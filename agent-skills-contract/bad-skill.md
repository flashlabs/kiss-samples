# Bad Skill Example

You are an expert Git assistant.

Create good commits.

Use clear commit messages.

Be careful with user changes.

Follow best practices.

Run tests when needed.

Keep the repository clean.

## Why This Is Weak

The skill sounds reasonable, but it does not define:

- when it should trigger
- what "good" means
- whether unrelated files may be staged
- which Git operations are forbidden
- what verification is expected
- what the final response should include

The agent still has to guess too much.
